Ти допомагаєш мені запустити й задеплоїти вебтрекер витрат «Трекер Олі й Марка» (Python, Beancount 3.2.3, Fava 1.30.16, Flask). Це домашнє завдання, частина 2. Поточна папка — корінь репозиторію. Спершу прочитай `README.md` повністю: він описує всі кроки, а цей промпт задає порядок, перевірки й обмеження.

## Мета

1. Локально: залежності встановлено, `uv run python check.py` закінчується «Усе зійшлося.» з кодом 0, сайт відкривається на http://127.0.0.1:5050 і проходить smoke-тест нижче.
2. Код у публічному репозиторії GitHub без секретів і без тестових записів.
3. Сайт працює на `https://<USERNAME>.pythonanywhere.com`: Марко входить з телефона за паролем, бачить звіт за місяць і може додати готівкову витрату.

## Жорсткі правила

- **Паролі й секрети ніколи не проходять через тебе.** Не проси мене написати пароль у чат, не друкуй вміст `.env`, не роби `cat .env`, не логуй хеші. `.env` створюю я сам командою `python -m tracker.passwd --write-env` у **своєму окремому терміналі**: вона інтерактивна (getpass), у твоєму Bash вона не спрацює. Наявність `.env` перевіряй лише так: файл існує, розмір більший за 0, у ньому є рядки, що *починаються* з `TRACKER_SECRET_KEY=` і `TRACKER_USERS=` (наприклад `grep -c '^TRACKER_' .env`), без виводу значень.
- `.env`, `.venv/`, `transactions-*.beancount` ніколи не потрапляють у git. Перед кожним комітом перевір `git status` і `git grep -n "scrypt:"` (має бути порожньо).
- Не змінюй `data/` (там штучні виписки з умови), не правь `transactions-*.beancount` руками (їх генерує `import.py`), не змінюй очікувані цифри в `check.py`. Якщо цифри не сходяться — шукай причину в імпорті чи правилах, а не підганяй перевірку.
- `manual.beancount` — сюди пишуться ручні записи. Після локальних тестів поверни його: `git checkout manual.beancount`.
- Нічого не публікуй і не пуш без мого явного «так»: створення публічного репозиторію і `git push` — тільки після підтвердження.
- Акаунти на GitHub і PythonAnywhere створюю я. У PythonAnywhere ти не заходиш: даєш мені точні команди й налаштування, я виконую й показую результат.
- Нових пакетів поза `pyproject.toml` без мого дозволу не став.
- Пиши мені українською, коротко: що зроблено, що перевірено, що від мене потрібно.

## Кроки

### 1. Оточення
- Визнач ОС і shell. Перевір `uv --version`. Якщо uv немає — покажи мені команду встановлення з README (розділ 2.1) і чекай; після встановлення попроси перезапустити термінал.
- Переконайся, що ти в корені проєкту (є `check.py`, `tracker/`, `data/`). У Windows zip часто дає дві вкладені папки з однаковою назвою.

### 2. Залежності й перевірка
- `uv sync`, потім `uv run python check.py`.
- **Ворота:** вихід містить `bean-check main.beancount: помилок немає ✓`, чотири контрольні цифри з ✓ (Оля 2 195,21 / 2 582,42, Марко 1 855,57 / 2 432,83), борг 1 713,81 / 1 566,47 і «Усе зійшлося.», код виходу 0. Покажи мені цей блок. Якщо ні — діагностуй і виправ, не йди далі.

### 3. `.env` для локального запуску
- Якщо `.env` немає або він порожній, попроси мене виконати у **своєму** терміналі в цій папці:
  `uv run python -m tracker.passwd --write-env --dev`
  і чекай, поки я скажу «готово».
- Перевір наявність ключів без виводу значень (див. правила).

### 4. Smoke-тест локально
- Запусти сервер у фоні: `uv run python -m tracker.web` (порт 5050).
- Перевір без входу через curl: `/`, `/add`, `/fava/` повертають 302 на `/login`; `/fava/<будь-що>/api/x` повертає 401; сторінка `/login` не містить сум у злотих.
- Попроси мене в браузері: увійти як `marko`; «Серпень» → Марко → змінні 1 855,57 зл; тапнути категорію — відкриваються операції; «+ Додати готівку» 1 зл → після перезавантаження запис у звіті; «Детально» відкриває Fava. Чекай мого підтвердження.
- Зупини сервер, виконай `git checkout manual.beancount`.

### 5. GitHub
- Якщо папка ще не git-репозиторій (`git rev-parse` падає) — `git init -b main`.
- Перевір `git status`, `git grep -n "scrypt:"`, що `.env` не відстежується (`git ls-files .env` порожньо). `uv.lock` комітимо.
- Закоміть зміни, якщо вони є.
- Якщо `gh auth status` ок — запропонуй створити публічний репозиторій `olya-marko-tracker` і запушити; виконай лише після мого «так». Якщо `gh` немає — дай мені команди з README, розділ 3.

### 6. PythonAnywhere
Проведи мене по README, розділ 4, по одному кроку, чекаючи результату кожного:
- клон, `mkvirtualenv --python=python3.12 tracker`, `pip install -r requirements.txt`, `python check.py` → «Усе зійшлося.» (попроси вставити вивід);
- `python -m tracker.passwd --write-env` **без** `--dev`, з **іншими** паролями, ніж локально;
- вкладка Web: Manual configuration, Python 3.12, Virtualenv `/home/<USERNAME>/.virtualenvs/tracker`, WSGI-файл з `deploy/pythonanywhere_wsgi.py` з підставленим USERNAME (підготуй мені готовий текст), Force HTTPS увімкнено, Reload.
- Якщо сайт показує помилку — попроси останні рядки з Web → Log files → error log і розбери причину.

### 7. Фінальна перевірка
Попроси мене з телефона: відкрити `https://<USERNAME>.pythonanywhere.com` → вхід як `marko` → звіт, контрольні цифри за серпень і вересень → додати 1 зл → перезавантажити → запис є. Окремо: `http://` має перекидати на `https://`.
